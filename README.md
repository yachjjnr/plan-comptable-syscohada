# Plan Comptable SYSCOHADA

Application publiée : https://yachjjnr.github.io/plan-comptable-syscohada/

Recherche et fonctionnement des comptes du **plan comptable SYSCOHADA révisé**
(AUDCIF 2017) : à quoi sert chaque compte, ses subdivisions, comment il se
débite et se crédite, ce qu'il ne faut pas y mettre.

Contient aussi des écritures types par situation : « je vends à crédit »,
« je paie un salaire », « déclaration de TVA ».

Installable sur mobile et consultable **hors connexion**.

Ce dépôt ne contient que le site compilé. Le code source n'est pas public.
